# SingStarter
Tone matching practice app for beginners.

Just a single static page, [open directly](https://htmlpreview.github.io/?https://github.com/JohanAR/SingStarter/blob/main/sing-starter.html) or save locally and open in your browser.

Needs permission to use your microphone.

Inspired by:
- ["The effect of visual and auditory feedback on adult poor-pitch remediation" Berglin, Pfordresher, Demorest (2021)](https://journals.sagepub.com/doi/10.1177/03057356211026730)
- ["Accuracy of pitch matching significantly improved by live voice model" Granot, Israel-Kolatt, Gilboa, Kolatt (2013)](https://pubmed.ncbi.nlm.nih.gov/23528675/)
